🎬 Phần mềm này làm gì?

Bỏ vào một video DÀI (buổi giảng, livestream, podcast…) → AI tự tìm những đoạn hay nhất, cắt thành nhiều video short 9:16 chuẩn viral: phụ đề động, hook 3 giây, logo, nhạc nền, thumbnail, nối CTA — và (tuỳ chọn) tự viết caption + đăng thẳng lên Lark Base của bạn.

Phần mềm chạy ngay trên máy bạn (không tải video lên mạng), mở ra như một trang web tại http://localhost:5178.

① Chuẩn bị trước khi cài

Bắt buộc

  • Máy Windows 10/11 hoặc máy Mac
  • ~5 GB trống + mạng internet (tải công cụ lần đầu)

Nên có

  • Tài khoản Claude (Anthropic) — "bộ não" chọn đoạn. Đăng ký tại claude.ai

Tuỳ chọn — thương hiệu

  • Logo PNG nền trong suốt
  • Vài ảnh chân dung (làm bìa/thumbnail)
  • Nhạc nền + video CTA bạn có quyền dùng

Tuỳ chọn — đăng Lark

  • Tài khoản Lark + một Bảng (Base) để chứa video

② Cài đặt (chỉ làm 1 lần)

▷ WINDOWS
  1. Bấm đúp CÀI ĐẶT (chạy 1 lần).bat
  2. Nếu báo "đóng và chạy lại" → đóng, bấm đúp thêm 1 lần để cài nốt
  3. Bước cuối đăng nhập Claude bằng trình duyệt (không cần AI thì đóng cửa sổ)
  4. (Tuỳ chọn) TẠO LỐI TẮT MÀN HÌNH.vbs → biểu tượng Desktop
  5. (Khuyên) BẬT TỰ KHỞI ĐỘNG LẠI.bat → tự hồi phục nếu bị tắt
▷ macOS
  1. Mở khoá lần đầu: mở Terminal, gõ chmod +x (có 1 dấu cách), kéo–thả cả 3 file … (Mac).command vào → Enter
  2. Bấm đúp CÀI ĐẶT (Mac).command (có thể hỏi mật khẩu máy)
  3. Bước cuối đăng nhập Claude (hoặc gõ n để bỏ qua)

Bộ cài tự lo: Node.js · FFmpeg · Python + Whisper · yt-dlp · Claude CLI.

③ Mở phần mềm

▷ WINDOWS   bấm đúp MỞ PHẦN MỀM.vbs (hoặc biểu tượng Desktop)

▷ macOS     bấm đúp MỞ PHẦN MỀM (Mac).command

Phần mềm mở tại http://localhost:5178. Không mở được? → mở trình duyệt gõ đúng địa chỉ trên.

④ Cấu hình lần đầu — tab ⚙️ Cấu hình

Mở phần mềm → bấm tab ⚙️ Cấu hình. Làm 1 lần, lưu vào máy này, áp dụng ngay (không cần khởi động lại).

🖼️ Thương hiệu & Thumbnail

  • Tên thương hiệu → in lên thumbnail + định hướng AI viết caption
  • Lĩnh vực / chủ đề → giúp AI chọn đúng "chất" nội dung của bạn
  • Màu nhấn → màu thương hiệu  ·  Thư mục ảnh chân dung → dựng bìa (tuỳ chọn)

→ Bấm 💾 Lưu thương hiệu. Muốn logo watermark: thả logo vào thư mục assets/ tên logo.png.

📤 Đăng lên Lark Base (tuỳ chọn — xem phần ⑤)

  1. Dán link bảng Lark của bạn (mở bảng trên trình duyệt → copy link)
  2. Bấm 🔎 Dò bảng & cột
  3. Chọn Bảng → chọn Cột đính kèm Video (bắt buộc); thêm cột Thumbnail / Nội dung / Loại / Fanpage nếu muốn
  4. Bấm 💾 Lưu cấu hình Lark → trạng thái chuyển "✅ Đã kết nối"

⑤ (Nâng cao) Bật tính năng đăng Lark

Đăng Lark cần công cụ lark-cli đã đăng nhập trên máy. Bộ cài không kèm sẵn — làm thêm 1 lần (mở Terminal / CMD):

npm install -g @larksuite/cli     # 1. Cài
lark-cli auth login               # 2. Đăng nhập (làm theo màn hình)
lark-cli auth status              # 3. Kiểm tra (thấy tên tài khoản = OK)
Điều kiện: tài khoản Lark bạn đăng nhập phải có quyền xem/sửa Bảng bạn dán link ở phần ④. Xong bước này, "Dò bảng" và nút "📤 Đăng Lark" mới hoạt động.
Không muốn cài? Cứ dựng video rồi tải về, tự kéo lên Lark bằng tay — mọi tính năng cắt/biên tập vẫn chạy đủ.

⑥ Quy trình hằng ngày

  1. Tab 🧠 Cắt tự động → kéo–thả video dài (hoặc dán link YouTube/FB/TikTok) → bấm chạy. AI phân tích rồi cắt nhiều short.
  2. Mỗi short hiện tông cảm xúc ❤️ và câu cao trào 🔥 trên timeline.
  3. Muốn sửa 1 short: bấm ✏️ Tinh chỉnh (kéo điểm cắt, sửa phụ đề, đổi tốc độ, chèn chữ, bật/tắt hiệu ứng) → 🔁 Dựng lại short này.
  4. Tải về kèm logo/nhạc/CTA — hoặc bấm 📤 Đăng Lark (nếu đã bật ⑤).

Các tab khác: 🎬 Video dài YouTube · 🎙️ Short lồng voice · ⭐ Đánh giá · ✂️ Tự biên tập · 🔎 Bóc ý tưởng · 📦 Hàng loạt.
