════════════════════════════════════════════════════════════
 ② CÀI ĐẶT  (chỉ làm 1 LẦN)
════════════════════════════════════════════════════════════
▷ WINDOWS
  1. Bấm đúp:  CÀI ĐẶT (chạy 1 lần).bat
  2. Nếu báo "đóng và chạy lại" → đóng cửa sổ, bấm đúp file đó
     THÊM 1 LẦN nữa để cài nốt.
  3. Bước cuối mở đăng nhập CLAUDE — đăng nhập bằng trình duyệt.
     (Không cần AI thì đóng cửa sổ, bỏ qua.)
  4. (Tuỳ chọn) "TẠO LỐI TẮT MÀN HÌNH.vbs" → có biểu tượng Desktop.
  5. (Khuyên) "BẬT TỰ KHỞI ĐỘNG LẠI.bat" → phần mềm tự hồi phục
     nếu lỡ bị tắt.

▷ macOS
  1. MỞ KHOÁ LẦN ĐẦU: mở Terminal (⌘ + phím cách → gõ Terminal),
     gõ  chmod +x  (có 1 dấu cách ở cuối), rồi KÉO–THẢ cả 3 file
     "... (Mac).command" vào Terminal → Enter.
  2. Bấm đúp:  CÀI ĐẶT (Mac).command   (có thể hỏi mật khẩu máy).
  3. Bước cuối đăng nhập Claude (hoặc gõ  n  để bỏ qua).

Bộ cài tự lo: Node.js · FFmpeg · Python + Whisper · yt-dlp · Claude CLI.

════════════════════════════════════════════════════════════
 ④ CẤU HÌNH LẦN ĐẦU — tab  "⚙️ Cấu hình"
════════════════════════════════════════════════════════════
Mở phần mềm → bấm tab  ⚙️ Cấu hình. Làm 1 lần, lưu vào máy này,
áp dụng NGAY (không cần khởi động lại).

🖼️ THƯƠNG HIỆU & THUMBNAIL (mỗi người một kiểu):
  • Tên thương hiệu    → in lên thumbnail + định hướng AI viết caption.
  • Lĩnh vực / chủ đề   → giúp AI chọn đúng "chất" nội dung của bạn.
  • Màu nhấn            → màu thương hiệu.
  • Thư mục ảnh chân dung → để dựng bìa thương hiệu (tuỳ chọn).
  → Bấm  💾 Lưu thương hiệu.

  (Muốn có logo watermark: thả logo của bạn vào thư mục  assets/
   với tên  logo.png  — phần mềm tự chèn.)

📤 ĐĂNG LÊN LARK BASE (tuỳ chọn — xem điều kiện ở PHẦN ⑤):
  1. DÁN LINK bảng Lark của bạn (mở bảng trên trình duyệt → copy link).
  2. Bấm  🔎 Dò bảng & cột.
  3. Chọn BẢNG → chọn CỘT đính kèm VIDEO (bắt buộc); chọn thêm cột
     Thumbnail / Nội dung / Loại / Fanpage nếu muốn.
  4. Bấm  💾 Lưu cấu hình Lark.  Trạng thái chuyển "✅ Đã kết nối".


════════════════════════════════════════════════════════════
 ⑤ (NÂNG CAO) BẬT TÍNH NĂNG ĐĂNG LARK
════════════════════════════════════════════════════════════
Đăng Lark cần công cụ "lark-cli" đã đăng nhập trên máy. Bộ cài KHÔNG
kèm sẵn — làm thêm 1 lần như sau (mở Terminal / CMD):

  1. Cài:        npm install -g @larksuite/cli
  2. Đăng nhập:  lark-cli auth login      (làm theo hướng dẫn trên màn hình)
  3. Kiểm tra:   lark-cli auth status      (thấy tên tài khoản = OK)

Điều kiện: tài khoản Lark bạn đăng nhập phải CÓ QUYỀN xem/sửa Bảng
mà bạn dán link ở PHẦN ④. Xong bước này, tính năng "Dò bảng" và nút
"📤 Đăng Lark" mới hoạt động.

KHÔNG muốn cài? Không sao — cứ dựng video rồi TẢI VỀ, tự kéo lên
Lark bằng tay. Mọi tính năng cắt/biên tập vẫn chạy đủ.
